## ⚠️ Important Note for Windows Users 
(If you want a shorter Version of this skip to line 35)

### Windows Defender may show a warning

When running this application for the first time, Windows Defender or Windows SmartScreen may display a warning and prevent the application from starting.

**This does not necessarily mean that the application contains a virus.**

This application is a small independent project and the `.exe` files are currently **not digitally signed** with a trusted code-signing certificate. Because of this, Windows may not be able to verify the publisher and may treat the application as an unknown or untrusted program.

This is especially common with applications from small or independent developers that have not yet built up a reputation with Microsoft's security systems.

### What you should know

* The application is provided directly through the **GitHub Releases** of this repository.
* The source code is currently not included in the repository.
* The application does **not require administrator privileges** to run.
* Windows may still display security warnings because the executable is not digitally signed.
* Only download releases from this repository and avoid executables from unofficial sources.

### If Windows blocks the application

If you downloaded the application from the official GitHub Release and Windows shows a SmartScreen warning, you can inspect the warning and the file before deciding whether to allow it.

**Do not disable Windows Defender or your antivirus software just to run this application.**

If your security software reports a specific malware detection rather than simply saying that the publisher is unknown, **do not ignore it**. Stop running the application and report the issue to me through the repository's issue tracker.

### Why is it not digitally signed?

Code-signing certificates can be expensive and are generally not necessary for a small personal project like this one. If the project grows in the future, I may add proper code signing to make Windows able to verify the publisher.

> **In short:** Windows may warn you because this is an independently developed, unsigned application — not because a security warning should automatically be ignored.
